# 数据库表说明

数据库名：`grading_app`，字符集：`utf8mb4`，引擎：`InnoDB`

## 表关系

```
grading_batches (批次)
  └── grading_records (批改记录，1:N)
        └── step_executions (步骤执行记录，1:N)

system_logs (系统日志，独立)
```

---

## grading_batches — 批改批次表

每次启动工作流创建一条记录，记录整批批改的汇总信息。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | INT | 自增 | 主键 |
| started_at | TIMESTAMP | CURRENT_TIMESTAMP | 批次开始时间 |
| ended_at | TIMESTAMP | NULL | 批次结束时间 |
| max_count | INT | 0 | 计划批改数量，0=无限循环 |
| status | ENUM('running','completed','stopped','error') | 'running' | 批次状态 |
| total_count | INT | 0 | 实际总处理数 |
| success_count | INT | 0 | 成功数 |
| fail_count | INT | 0 | 失败数 |

---

## grading_records — 批改记录表

每张试卷的批改详情，一个批次对应多条记录。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | INT | 自增 | 主键 |
| batch_id | INT | - | 所属批次 ID，外键→grading_batches(id) |
| task_id | VARCHAR(50) | - | 任务标识，如 task_160933 |
| screenshot_path | VARCHAR(500) | NULL | 截图完整文件路径 |
| score | INT | NULL | AI 评分结果（0-6） |
| status | ENUM('success','fail','error','skipped') | 'success' | 批改状态 |
| error_message | TEXT | NULL | 失败时的错误信息 |
| vlm_response | TEXT | NULL | 大模型原始返回文本 |
| vlm_model | VARCHAR(100) | NULL | 使用的模型名称 |
| duration_ms | INT | NULL | 单次批改耗时（毫秒） |
| score_secondary | INT | NULL | 副模型评分 |
| vlm_response_secondary | TEXT | NULL | 副模型原始返回 |
| vlm_model_secondary | VARCHAR(100) | NULL | 副模型名称 |
| grading_mode | ENUM('single','dual') | 'single' | 批改模式：single=单评，dual=双评 |
| score_consistent | TINYINT(1) | NULL | 双评一致性：1=一致，0=不一致或失败，NULL=单评 |
| screenshot_human_path | VARCHAR(500) | NULL | 人看截图完整路径 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 记录创建时间 |

索引：`idx_batch_id(batch_id)`、`idx_created_at(created_at)`

---

## step_executions — 步骤执行记录表

每条批改记录中各工作流步骤的执行明细（截图、评分、清分、确认等）。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | INT | 自增 | 主键 |
| record_id | INT | - | 所属批改记录 ID，外键→grading_records(id) |
| step_id | VARCHAR(50) | - | 步骤标识，如 screenshot、evaluate、clear、confirm |
| step_type | VARCHAR(50) | - | 步骤类型，如 ScreenshotStep、VLMEvalStep |
| status | ENUM('start','success','fail') | 'start' | 步骤状态 |
| duration_ms | INT | NULL | 步骤耗时（毫秒） |
| error_message | TEXT | NULL | 失败时的错误信息 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 执行时间 |

---

## system_logs — 系统日志表

应用运行日志，按级别和模块分类存储。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT | 自增 | 主键 |
| level | ENUM('DEBUG','INFO','WARNING','ERROR','CRITICAL') | 'INFO' | 日志级别 |
| module | VARCHAR(100) | NULL | 来源模块名，如 GradingApp |
| message | TEXT | NULL | 日志内容 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 日志时间 |

索引：`idx_created_at(created_at)`、`idx_level(level)`
